InternTrack

Internship Tracking Application

InternTrack is a student-focused mobile application that helps users discover and manage internship opportunities and track their applications.

Features

  • Internship search
  • Application tracking
  • Application status management
  • Student profile management
  • Firebase-based data storage

Project Information

This is a student PBL project developed using Android Studio, Kotlin, Jetpack Compose, and Firebase.
