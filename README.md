# InternTrack 🎓

**InternTrack** is a modern Android application built to streamline the internship hunt for students. It offers a centralized dashboard to track applications, discover new roles, and manage professional progress.

## 🚀 Features

- **Application Tracker**: Monitor the status of your applications (Applied, Interview, Offer, Rejected).
- **Internship Search**: Search through curated recommendations from top-tier companies.
- **Quick Stats**: Get an immediate overview of your interview progress and offers.
- **Modern UI**: Built entirely with Jetpack Compose and Material 3 for a sleek, responsive experience.

## 🛠️ Technical Stack

- **UI**: Jetpack Compose (Material Design 3)
- **Language**: Kotlin 2.2.10
- **Build System**: Gradle 9.6.0 (Kotlin DSL)
- **Architecture**: MVI/MVVM State-driven UI

## 📦 How to Run

1. Clone or unzip the project.
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Ensure you have **JDK 17+** configured.
4. Let Gradle sync and build the project.
5. Run on an emulator or physical device (API 24+).
